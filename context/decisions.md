# Decisions Log — "912 Days"

A running record of design and build decisions. **Append a new dated entry each working session** — don't overwrite old ones. This is the project's memory: when a choice is made (or reversed), log *what* was decided and *why*.

**Format:** newest entries at the top. Each entry = date, what changed, and the reasoning.

---

## How to use this file (AI + owner)

- Add an entry whenever you make a real decision: a design direction, a scope call, a data assumption, a tradeoff, a reversal.
- Keep entries short — a sentence or two of *what* and *why* is enough.
- Note reversals explicitly (e.g. "Changed from X to Y because…") so the history stays honest.
- Reference the relevant scene/phase where useful (e.g. "Scene 4," "Phase 1").

### 2026-09-04 — Hover-to-inspect on growth chart + diaper bars, diaper headline line breaks
- **Growth chart switched from click-to-toggle to hover/focus-to-reveal**: the per-point callout (age/length/percentile) now shows on `mouseenter`/`focus` and hides on `mouseleave`/`blur`, instead of requiring a click to open and a second click to close. ### 2026-09-04 — Fixed faces getting cropped out of carousel photos
- **Root cause:** most source photos are portrait-orientation phone shots; forced into the carousel's 4:3 landscape box via `object-fit: cover` with the CSS default `object-position: center`, the crop symmetrically trims top and bottom — which, for a portrait photo, cuts a lot of height and often removed the top of the frame where faces usually are.
- **Fix:** `PhotoCarousel.jsx`'s `<img>` now sets `object-position: 50% 20%` by default (biases the visible crop window toward the top of the source image), with an optional per-photo `focus` field on `storyData.js` photo entries to override it for any individual photo that still needs different framing.
- **Verified against all 24 photos across all 5 locations** (Please Touch, Zoo, Aquarium, PG's, Mom Mom's) in-browser — the single top-biased default fixed every case; no per-photo `focus` overrides were needed this round. Left the override mechanism in place for future photos that might need it.
